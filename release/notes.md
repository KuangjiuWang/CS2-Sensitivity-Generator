Windows 和 macOS 共用一个版本号，请按设备选择下载文件。

- Windows x64 选择 `CS2-Sensitivity-Generator.exe`。
- Apple 芯片 Mac 选择 `CS2-Sensitivity-Generator-macOS-arm64.zip`。
- Intel Mac 选择 `CS2-Sensitivity-Generator-macOS-x86_64.zip`。

本版加入 macOS 原生相对鼠标输入。六项训练切换时保持全屏，盲测每档覆盖全部六项，灵敏度建议按项目成对比较。macOS 构建以 15 为目标，应用包未经 Apple 公证。
